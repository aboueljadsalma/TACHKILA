# TACHKILA – Atlas FC

## Présentation

TACHKILA est une application web responsive permettant de gérer l’effectif d’une équipe de football et de créer une composition tactique en **4-4-2**.

## Fonctionnalités

- **Gestion des joueurs :** ajouter, modifier et supprimer des joueurs.
- **Gestion de l’effectif :** afficher la liste des joueurs et le nombre total de joueurs.
- **Affectation des joueurs :** attribuer chaque joueur à une position compatible avec son poste.
- **Composition tactique :** visualiser les 11 positions sur un terrain de football.
- **Gestion des positions :** distinguer les positions libres et occupées.
- **Validation du formulaire :** vérifier les informations saisies et éviter les doublons de numéros.
- **Sauvegarde des données :** conserver les joueurs dans le navigateur grâce à `localStorage`.
- **Interface responsive :** adapter l’affichage aux différentes tailles d’écran.

## Technologies utilisées

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- DOM
- LocalStorage

## Composition tactique

L’application utilise un schéma tactique **4-4-2**, composé de :

- **GB :** Gardien de but
- **DEF :** Défenseurs
- **MIL :** Milieux de terrain
- **ATT :** Attaquants
